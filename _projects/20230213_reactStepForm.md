# 🎓 こどもまなびLAB 応募ステップフォーム

子ども向けITプログラミング教室「こどもまなびLAB」を想定した
**コース診断付きの応募ステップフォーム**です。


## プロジェクト概要
- **目的**：子どもの興味から最適なコースを提案する、診断型の応募フォームを制作。  
- **想定ユーザー**：お子さんの学びに関心を持つ保護者と、その子ども本人。
- **開発環境**：React + TypeScript
- **制作期間**：約2週間（2023年1月28日〜2月13日）
- **開発規模**：個人制作
- **公開URL**：[https://try-react-app-step-form.vercel.app/](https://try-react-app-step-form.vercel.app/)


## UX設計の背景

このフォームは「こどもまなびLAB」の想定利用者を明確にし、  
**親子が一緒に“学びのきっかけ”を選べる体験**を目指して設計しました。

### 想定ユーザー（ペルソナ）

| 立場 | 特徴・課題 |
|------|-------------|
| **保護者（父）** | 教育熱心だがプログラミング経験がなく、「どこから始めればいいか分からない」。<br>家庭の金銭的余裕はあり、教育投資に意欲的。 |
| **保護者（母）** | 「子どもの気持ちを大切にしたい」と考えており、無理に学ばせたくはない。<br>パパに任せているが、楽しめる教育なら賛成。 |
| **子ども本人** | 主体的に学ぶ存在である一方、これまで「選択の場」に参加してこなかった。<br>自分で「これを作ってみたい！」と言えるきっかけがほしい。 |

👉 本プロジェクトでは、**「親だけでなく、子ども本人も一緒に選べるUI」**を目指しました。


## クリエイティブコンセプト

**「作りたいものを、親子でいっしょに考えられるフォーム」**

保護者が主導する応募手続きの中で、  
子ども自身の“やってみたい”を引き出すようデザインしました。


## デザインの方針

| 重視したこと | 実装上の工夫 |
|---------------|---------------|
| **ユーザーと対話する** | - 各画面で「案内役」が会話するように誘導<br>- 次に進む操作を“会話の続き”として体験できる構成 |
| **迷わせない** | - 「作ってみたい／興味はない／わからない」の3択に限定<br>- 戻るボタンを常に表示し、安心感を持って進めるように設計 |


## 主な機能

- ステップ形式フォーム（入力 → 興味診断 → 結果表示）
- コース診断ロジック（点数集計でおすすめを自動判定）
- ステップ進行を可視化するプログレスバー 


## コース診断の仕組み

### 質問内容
9問（各コース3問ずつ）

- **BP**：はじめてのプログラミングコース（例：ネコの迷路ゲーム）  
- **GA**：ゲーム＆アプリクリエイトコース（例：オリジナルRPGを作る）  
- **WD**：Web＆テクノロジーチャレンジコース（例：AIチャットを作る）

### スコアリングルール

| 選択肢 | 加点内容 |
|--------|-----------|
| 作ってみたい | +1 |
| 興味はない | -1 |
| わからない | 0 |

合計点が最も高いコースを「おすすめコース」として表示します。
また、もしコースが同率だった場合「まずは体験してみる」に誘導しています。

どの回答でも必ず結果が出るようにし、  
子どもが「自分で選んだ」という実感を得られるように設計しました。


## デザイン・UI面の工夫

- やさしい配色と丸みのあるボタンで**親しみやすさと安心感**を演出  
- ステップ進行バーで「あと少し！」が視覚的にわかる  
- アイコンやイラストで子どもの興味を引くビジュアル設計  
- 会話風の文体で「UIが話しかけてくれる体験」を意識
